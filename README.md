## Entry

> Are you a CAPTCHA? Because I'd click every traffic light to prove I'm human — and for you, I'd fail on purpose.

111 characters. One line, one joke: a CAPTCHA is a machine that tests whether you are human — so the speaker turns the test around and volunteers to fail it on purpose for the machine. No batteries, charging, or rebooting; the laugh comes from the machine premise itself, and it reads like something a person would actually say to a machine.

## Run

```

```

Writes the line to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`). Deterministic, no dependencies, no network, no cost.
